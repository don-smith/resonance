# Resonance

Resonance is a local-first, peer-to-peer team workspace built on Tauri, Iroh, and Yjs. It gives enterprise teams a collaborative AI-native environment — shared documents, persistent conversations, and an agent panel — where all data lives on team machines and syncs over encrypted QUIC connections, with no cloud dependency required.

## Design documentation

All vision, requirements, architecture decisions, and open questions live in [`context/`](./context/). That directory is the authoritative source of record for the project and uses the LiveStore VRS convention (vision → requirements → spec → decisions → delta).
